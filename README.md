# Racing Team Database

A complete SQL database for managing a ficticious scenario where you have your own competitive racing team.

This project contains a comprehensive SQL script that defines and manages a racing team database. The script includes:

- Creation of main tables (teams, drivers, cars, races, results, etc.)
- Initial data inserts
- Stored procedures for automating critical tasks
- Triggers for business rule enforcement

## Database Structure

The database manages:

- Teams and their members
- Driver information and contracts
- Car specifications and maintenance
- Race schedules and results
- Championship standings

## Automation Logic

Includes programmed logic via triggers and stored procedures that automatically handle:

- Points calculation after races
- Driver contract validation
- Car assignment verification
- Historical data logging

## Setup

1. Run the provided SQL script on your database management system (MySQL/PostgreSQL recommended)
2. The script will create all tables, indexes, and relationships
3. Initial data will be inserted automatically
4. Stored procedures and triggers will be compiled and activated
